# سایت کیانا — نسخه ۳

این نسخه شامل ۹ عکس واقعی داخل پوشه `assets/` است و عکس‌ها دیگر وابسته به انتخاب موقت مرورگر نیستند.

## انتشار روی GitHub Pages
1. محتویات این پوشه را داخل Repository آپلود کن؛ فایل `index.html` باید در ریشه Repository باشد.
2. از Settings → Pages، گزینه Deploy from a branch را انتخاب کن.
3. Branch را روی `main` و Folder را روی `/ (root)` بگذار.
4. Save را بزن و بعد از چند لحظه لینک سایت ساخته می‌شود.

## نکته حریم خصوصی
اگر Repository یا GitHub Pages عمومی باشد، عکس‌های داخل سایت نیز عملاً قابل دسترسی خواهند بود. بخش «PRIVATE ROOM» در این نسخه فقط ظاهری است و رمز جاوااسکریپتی امنیت واقعی ایجاد نمی‌کند.

برای اضافه‌کردن آهنگ، فایل واقعی را با نام `our-song.mp3` جایگزین فایل موجود کن.
